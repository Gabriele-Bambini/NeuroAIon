# Risk-of-bias worksheet library

Blank, fill-in signalling-question worksheets for every supported instrument. Copy the worksheet for the design at hand and complete it while reading each study's full text.

| Instrument | Use for | Form |
|---|---|---|
| RoB2 | randomized trials | `RoB2_blank.md` / `RoB2_blank.csv` |
| ROBINS-I | non-randomized studies of interventions | `ROBINS-I_blank.md` / `ROBINS-I_blank.csv` |
| ROBINS-E | non-randomized studies of exposures | `ROBINS-E_blank.md` / `ROBINS-E_blank.csv` |
| QUADAS-2 | diagnostic accuracy studies | `QUADAS-2_blank.md` / `QUADAS-2_blank.csv` |
| Newcastle-Ottawa | cohort / case-control studies | `Newcastle-Ottawa_blank.md` / `Newcastle-Ottawa_blank.csv` |
| AMSTAR-2 | systematic reviews | `AMSTAR-2_blank.md` / `AMSTAR-2_blank.csv` |
| JBI | various designs (JBI checklists) | `JBI_blank.md` / `JBI_blank.csv` |
| PROBAST | prediction-model studies | `PROBAST_blank.md` / `PROBAST_blank.csv` |
